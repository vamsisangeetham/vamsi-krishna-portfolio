# Vamsi Krishna S — Portfolio

A responsive React + Vite portfolio based on the resume provided.

## Requirements
- Node.js (current LTS recommended)
- npm

## Run locally
1. Extract the ZIP.
2. Open the `vamsi-portfolio` folder in VS Code.
3. Open the terminal in that folder and run:

   ```bash
   npm install
   npm run dev
   ```

4. Open the local URL shown in the terminal (usually `http://localhost:5173`).

## Create a production build
```bash
npm run build
npm run preview
```

## Before publishing
- Add your real LinkedIn URL and GitHub profile if you want them displayed.
- Add approved project screenshots or public store links.
- Confirm you are comfortable publishing the phone number and email shown on the resume.
- Review project descriptions and metrics for accuracy and permission to share.
- The portfolio currently does not include a resume PDF download button; add the approved resume file to `public/` and link it if desired.
